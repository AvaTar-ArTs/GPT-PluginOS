# Checkpoint: Runtime v0.2

Date: 2026-08-20

## Why this checkpoint exists

The project had reached a mature architecture/documentation/product-surface stage but still lacked an executable control-plane core. This checkpoint marks the transition from illustrated behavior to verified runtime behavior.

## Added

- installable Python package and `pluginos` CLI
- canonical provider/capability/policy seed registry
- strict graph invariants
- deterministic route engine and hard policy constraints
- overlap, audit, graph, scan, explain, and metadata-benchmark views
- deterministic lockfile and lockfile diff
- compiled route projection
- Studio export path
- JSON Schema contracts
- zero-dependency unit tests and GitHub Actions CI

## Important correction

The demo provider dataset referenced more capabilities than the demo capability catalog declared. v0.2 expands the canonical capability catalog so every provider edge resolves.

The `quality-first` policy was also tuned so its behavior matches its name for the seed `media.image.upscale` example: Magnific outranks Cloudinary under that policy while cost-aware/private policies may select differently.

## Preserved boundary

Provider selection does not imply authorization. PluginOS remains a read-only advisory control plane. Execution remains outside this repository.

## Verified locally

- 17 unit tests pass
- package installation succeeds using `pip --no-build-isolation --no-deps`
- installed artifact runs validate/scan/route/overlaps/benchmark/lock/compile/export-site
- route output explicitly reports `authorization_implied: false`
